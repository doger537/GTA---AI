# Состояние проекта — 3 ноября 2026

Экспериментальный прототип для Windows. Самостоятельная езда до GPS-метки пока не подтверждена.

- C#-мост: ограниченный ввод, F8/фокус, синхронные JPEG дороги и PNG HUD/миникарты.
- Node.js: OCR, дорожная семантика, детектор машин и поиск пути. ONNX выполняется в рабочих потоках с последовательным доступом к DirectML.
- Python: экспериментальное обучение и адаптер виртуального геймпада, по умолчанию mock.
- В новой ручной поездке записано 867 наборов изображений. На 40 размеченных кадрах передача верна 40/40, скорость подтверждена 24/40, путь найден 3/40. Это диагностическая поездка, не независимая приёмка.
- Одиночная 7 исправлена дополнительной проверкой. Многозначные числа с 7, доступность пути и направление камеры остаются задачами.

Полный локальный набор из 105 JS и 16 Python проверок проходил с моделями и записями, не включёнными в Git. Проверки без этих активов: `npm run test:core` из `outputs/GtaAutopilot`.
