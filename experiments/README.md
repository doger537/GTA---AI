# Эксперименты

Инструменты сравнения, диагностики и профилирования — в `tools/`. Запуск из корня: `node experiments/tools/benchmark-road.mjs ...`. Некоторые инструменты допускают живой захват только при явном выборе соответствующего режима; перенос каталогов сам их не запускает.

`recordings/`, `observation-recordings/` и `runs/` содержат большие локальные данные, исключённые из Git. Публикуемые отчёты — в [docs/reports](../docs/reports). Не перезаписывайте старые результаты новой серией. Снимки кода, временные трассы и материалы миграции — в игнорируемом `work/`.
