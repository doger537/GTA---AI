# Дополнительные development-случаи 6/8/9

Три исходных native HUD PNG из development-записей 8 ноября. Выбраны по структуре символа и размечены визуально до проверки нового OCR. Это примеры разработки и регрессии, не независимая оценка. Запись validation от 9 ноября здесь не используется.

`labels.json` хранит визуальную скорость/передачу, SHA-256, исходную сессию, имя кадра, sequence и capture timestamp. `six-colour` — дополнительная 6; `eight-scale` защищает от потери 8 на слишком большом растре; `nine` — одна реальная 9 на ярком фоне. Единственный кадр 9 не подтверждает полный диапазон освещения или точность на других поездках.

Полный `npm test` выполняет реальное OCR трёх PNG; `npm run test:core` проверяет структуру, поворот и отказ от слабого/противоречивого OCR без большого OCR-актива.
