# Native HUD — реальные development-случаи 8 ноября 2026

Шесть исходных PNG сохранены без перекодирования из пассивных записей. Источник каждого файла, SHA-256, исходное время/sequence, геометрия и визуальная разметка находятся в `labels.json`. Разметка выполнена по contact sheets до просмотра прогнозов OCR. Это диагностические примеры, а не независимая validation-выборка.

Положительные контроли: ясный прочерк0 и цифра7. Найденные случаи отказа:6,8, прочерк на фоне дороги/тени и прочерк при передачеR. Ошибка чтения остаётся unknown; нельзя исправлять её подстановкой нуля по одному тексту OCR.

Из корня, с локальным OCR-активом:

```powershell
node experiments/tools/evaluate-calibration-hud.mjs --strict
```

`--strict` возвращает ненулевой код, пока все визуально подтверждённые значения не читаются точно. Этот диагностический набор намеренно не включён в обязательный CI до исправления обнаруженных отказов. Он фиксирует недостигнутую цель. Стандартные регрессии75→15 и7→0 по-прежнему обязательны. Углы, метры и готовая калибровка из этих изображений не выводятся.
