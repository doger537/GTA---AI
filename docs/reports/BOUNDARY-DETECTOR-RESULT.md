# Границы дороги и нестабильность детектора: офлайн-разбор

3 ноября 2026. Проверены три видимых отрезка бордюра и пять кадров одного эпизода с грузовиком. Рабочая система сохраняется: у GTA-кандидата найдены кратковременные пропуски детектора. Игра/мост/ввод не запускались; пороги, веса и leases не менялись.

## Границы

На увеличенных исходниках вручную проведены три приближённые линии бордюра. Для оценки растеризованы полосы по обе стороны: от 0,025 до 0,045 ширины изображения от линии; полоса неопределённости ±0,01 исключена. Линии и полосы визуально проверены до подсчёта. Это диагностические сцены, выбранные по прежним ошибкам, с уже известными прогнозами, а не слепая валидация. Полосы не являются полными масками сцены, а расстояние в пикселях не задаёт метрический зазор машины.

| Сцена | Дорога сохранена, baseline / GTA | Недорожная полоса ошибочно «свободно», baseline / GTA |
|---|---:|---:|
| development 000000, бордюр у травы | 61/82 / 44/82 | 35/80 / 0/80 |
| development 000618, край тротуара | 0/32 / 13/32 | 19/32 / 0/32 |
| другая сессия 000158, правый тротуар | 0/70 / 65/70 | 0/71 / 0/71 |

Использована прежняя консервативная обработка: rear-исключения, маски препятствий и боксы; baseline сохраняет штатное объединение. Ячейки внутри полос коррелируют. GTA здесь лучше отделяет недорожную область, но в 000000 сохраняет меньше отмеченной дороги. Эти сцены не дают общей точности по городу.

## Исправление прошлой разметки

Трассировка 000158 выявила ещё одну неверную метку: участок 2 с центром (0,80; 0,50) находится со стороны дороги, а в прошлом отчёте был назван тротуаром. Он исключён из повторной оценки после просмотра прогнозов; исходная разметка и обе прежние версии результатов сохранены. Прежний вывод о ложном свободном тротуаре GTA именно на этом участке отозван.

Итог повторного source-review: **97** частичных участков вместо 98. По второй сессии отрицательных ячеек теперь 144; ложных свободных baseline 4/144 (пол стройки), GTA 0/144. Остальные метрики прошлого отчёта неизменны. Это уточнение диагностических меток, не независимая оценка и не доказательство отсутствия иных ошибок тротуара.

## Пропуск грузовика

Вручную просмотрены исходники 001088, 001093, 001098, 001103, 001108 одной исторической сессии. На каждом отмечен небольшой видимый участок передней части грузовика, отдельно от своего пикапа. Пять кадров охватывают лишь один короткий эпизод, не пять независимых случаев. Время/скорость движения и вмешательства для этих кадров заново не размечались; ездовых результатов нет.

| Кадр | Максимальная сырая уверенность other_car у центра участка | Участок закрыт препятствием baseline / GTA после боксов |
|---|---:|---:|
| 001088 | 0,867 | 12/12 / 12/12 |
| 001093 | 0,345 | 12/12 / 0/12 |
| 001098 | 0,888 | 12/12 / 12/12 |
| 001103 | 0,837 | 12/12 / 12/12 |
| 001108 | 0,0009 | 12/12 / 0/12 |

На всех этих участках road и итоговое free равны нулю у обеих систем. То есть отсутствие препятствия здесь не превратилось в ложное «свободно», но GTA теряет объект в двух из пяти проверенных кадров. Baseline в этом эпизоде стабильнее.

Сырые боксы отбирались по содержанию центра вручную размеченного участка; такая проверка сама по себе не доказывает совпадение с объектом. Координаты и top-3 по каждому классу сохранены для аудита. В 001093 максимум other_car ниже неизменённого confidence 0,6, а в 001108 сигнал около центра практически исчезает ещё до NMS. Одним NMS это не объясняется; снижение порога на одном эпизоде не принято как исправление. Общая road-детекция может содержать объект внутри большого бокса, но это не означает, что road-маска помечает его дорогой.

При разработке диагностического инструмента обнаружена мутация выходного массива внутри штатного postprocess. Финальная версия снимает копии сырых тензоров **до** NMS. Первый ошибочный диагностический запуск сохранён в gta/ с отметкой INVALID; использовать gta-v2/diagnostic.json. Маски обоих запусков не менялись; ошибка касалась только таблицы сырых scores/boxes.

## Решение и дальнейшая очередь

GTA не заменяет рабочее зрение. Сохранён конкретный регрессионный эпизод: частично закрытый грузовик ночью при повороте камеры. Следующие изменения детектора/трекера должны проверяться на этом эпизоде и новых отдельных сессиях; временное удержание бокса нельзя вводить без компенсации движения камеры и проверки ложных препятствий.

По общему плану остаются: полные ручные маски более широкого набора сцен; новая отложенная поездка для дороги и HUD; проверка OCR на низких скоростях/бликах; фактический возраст наблюдений при активной GTA; затем измеренная калибровка газа/тормоза/руля. Маршруты GPS и объезд движущихся препятствий допускаются после этих зависимостей. Текущие старые свободные записи не содержат целей GPS; такие метки не создавались.

Для следующей записи подготовлен OFFLINE-NEXT-VALIDATION.md. Её запуск, живые калибровки и прохождение всего плана офлайн не выполнялись: нужны наблюдаемые начальные условия и новые данные.
