# Следующая проверочная сессия — подготовка, не результат

Этот протокол не запускает игру и не даёт допуск к автоматическому движению. Рабочее восприятие остаётся baseline. GTA ONNX только кандидат; см. BOUNDARY-DETECTOR-RESULT.md.

1. Новую запись заранее назначить validation и не использовать для обучения/подбора порогов. Хранить исходные синхронные road/HUD/minimap, времена, sequence, declared camera и завершение/паузы фокуса. Старую защищённую поездку не использовать для выбора моделей.
2. Сценарии, которых не хватает: ночь и блики, низкие скорости 0–12, цифра 7, замедление до подтверждённой остановки; дорога рядом с бордюром; другой кузов; грузовик, частично закрытый своим автомобилем; поворот камеры при неподвижной машине. Эти условия фиксировать по изображению, а не придумывать по клавишам.
3. Первую новую сессию записывает человек. Автоматические газ/руль/тормоз не нужны. Перед живым запуском проверить текущий кадр, фокус/F8, отсутствие параллельных исполнителей и реальное исходное состояние; нейтраль не гарантирует остановку.
4. Заранее выбрать равномерные кадры и отдельные непрерывные интервалы по журналу сценариев. Сначала вручную разметить исходные изображения без прогнозов: HUD unknown при неоднозначности; видимые road/nonroad/ego/vehicle и неизвестные границы. Не смешивать соседние кадры разных частей одной поездки как независимые сессии.
5. Запустить неизменённые baseline/GTA и считать false-free отдельно от пропусков дороги, обнаружение препятствий отдельно от road; проверить маски и боксы на коротких последовательностях. Не принимать модель только по доступности геометрических кандидатов пути.
6. Возраст наблюдений и p50/p95 измерить отдельным пассивным shadow-профилем при активной GTA; офлайн 104/115 мс кандидата не подставлять вместо этого результата. Лимиты 450/250 мс сохранить.
7. Калибровку газа/остановки запускать только после проверенного чтения HUD в её условиях. По пять повторений каждого режима, затем независимая проверка остановки; руль обоих знаков — после этого. До проверки масштаба сохранять относительную реакцию/время, не выдумывать метры и углы колёс.

Эта очередь соответствует DEVELOPMENT-PLAN.md. Пока нет новых наблюдений, пункты 2–7 нельзя отмечать пройденными.
