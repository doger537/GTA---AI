# Проверка управления GTA V

Проверка проведена в одной игровой сессии, ночью и под дождём. Это наблюдения отдельных проб, не статистическая оценка надёжности. Программа отправляет команды, а агент принимает решения по полученным кадрам.

| Проверка | Результат | Качество |
| --- | --- | --- |
| W / A / S / D пешком | Проверены отдельно; направление движения меняется | Хорошее для коротких движений |
| Бег W + Shift | Одновременные клавиши сработали, видна анимация бега | Работает; скорость в метрах в секунду не измерялась |
| Прыжок W + Space | Видна фаза прыжка | Работает в этой пробе |
| Выбор оружия | Колесо Tab открывается; после выбора виден счётчик патронов | Работает, управление колесом потребовало дополнительного Tab |
| F | Персонаж сел в стоящий автомобиль | Работает для посадки; другие контексты F не проверялись |
| Езда | Проверены разгон W, левое/правое руление, S, задний ход и ручной тормоз Space | Ввод работает, точность маневрирования низкая |
| Препятствия | Столб пройден сбоку; при подходе к машине персонаж упёрся в стену и потребовал коррекции; автомобиль столкнулся с опорой моста | Ненадёжно |
| Маршрут GPS | Поставлена точка с расстоянием 196 м; минимальный наблюдавшийся остаток 99 м; столкновение с опорой; цель не достигнута | Тест не пройден |

## Скорость

- В журнале 26 команд с измерением полного запроса «действие + кадр». Отдельная проверка колеса оружия записана отдельно.
- Команды задавались на 120–3500 мс. Эта длительность — намеренное удержание, а не задержка связи.
- Разница между временем полного запроса и временем выполнения действия: **131–223 мс**, среднее **175 мс**. В неё входят ожидание свежего кадра, получение ответа и накладные расходы; это не время реакции игры на начало нажатия.
- Возраст возвращённых кадров: **51–72 мс** по серверным меткам.
- Попытка GPS-маршрута заняла **88,74 секунды** от начала первого участка до фиксации результата, включая анализ, остановки и коррекции. Сокращение показания расстояния составило 97 м; это не измерение фактически пройденного пути и не скорость автомобиля.
- Время решения агента между запросами в показатели 131–223 мс не включено.

## Вывод

Передача клавиш и базовые действия работают. Основное ограничение — выбор направления, оценка сцены и коррекция между командами. Автономное вождение и устойчивый обход препятствий пока ненадёжны. Нельзя переносить успешный короткий ввод на обещание безопасного или быстрого прохождения маршрута.

В конце команды остановлены. Автомобиль остался возле опоры моста. Полный журнал замеров — `test-results.json`.
