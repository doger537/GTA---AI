# Первые 12 отметок видимого асфальта

Отчёты рассчитаны на коде `8ba41826aa9d5e8a8066a29d3aa307e912e956bc`. Контрольный файл с пустыми полилиниями вернул `why_not_scored.reason=no_asphalt_edge_marks` и `counts.empty=12`. Ранее присланный JSON был статусом готовности данных на версии575c62c.

Из прежних 25 коротких случаев выбраны по шесть равномерных позиций ночной и дневной development-сессий. Codex просмотрел все 12 оригинальных JPEG в исходном разрешении и поставил полилинии. Предыдущие диагностические предсказания уже были известны. Метки требуют проверки человеком.

Начальная высота полилинии совпадает с центром фактического стартового ряда планировщика. Начальный X выбран на визуально различимом асфальте на этой высоте. Это проверка доступного вертикального диапазона вдоль размеченной линии, для проверки точного стартового X нужен отдельный разбор. Дальняя точка отмечает последнее различимое продолжение поверхности по выбранной линии. Причины ограничения включают темноту, изгиб, перекрёсток и машины.

При этих отметках 11 кадров дают меньше13 рядов, один позволяет13. Дополнительно посчитана чувствительность к смещению дальней точки на4 пикселя исходного изображения. В10 случаях недостаток сохраняется, один по-прежнему позволяет13, дневной000022 становится пограничным. Этот сдвиг — проверка чувствительности, его размер выбран вручную и не является статистической оценкой ошибки разметки.

Сохранённые предсказания к этому прогону не подключались. Поэтому `first_blocker.none=1` означает достаточный диапазон видимости у одного кадра, дальнейшие ограничения маски и поиска для него не оценены. Геометрическая калибровка отсутствует, `metres_known=false`.

Эти результаты уточняют трактовку [сравнения кандидатов](CORRIDOR-CANDIDATES.md). Число3/40 остаётся результатом штатного критерия на масках. Его нельзя целиком трактовать как ошибку моделей или переносить результат этой подвыборки на все25 случаев. Для выбранных10 кадров требование13 рядов выходит за пределы размеченного диапазона даже при указанном смещении точки.
