# Чтение 11 — офлайн-доработка 9 ноября 2026

Development-кадр с 11 км/ч теперь читается правильно. Добавлена проверка двух отдельных полностью видимых единиц и отдельное OCR каждого символа. Даже два уверенных whole-string ответа 1 не могут стать принятой скоростью 1 при исходной геометрии 11: требуется подтверждение обеих единиц, иначе результат неизвестен.

## Реализация

`eleven-speed.mjs` использует прежнюю сегментацию белых пикселей >210. Допускаются ровно два разделённых символа одинаковой высоты/положения: узкий вертикальный сплошной стержень с выступом влево сверху. Один символ, три символа, касание, обрезка, смещение по высоте, ровные полосы и другие цифры отвергаются.

Каждая единица читается в двух фиксированных размерах 80/100 пикселей, nearest, PSM8. Все четыре ответа обязаны быть 1 с конечным confidence≥75. Whole-string 1 допустима только как подтверждаемая потеря одной из двух видимых единиц; уверенные 0/10/12/17/111 запрещают восстановление. При слабом/противоречивом ответе возвращается unknown. Настройки worker восстанавливаются при исключении.

Fallback включён новым флагом native HUD; старые пользовательские ROI сами его не включают. Прежняя сегментация семёрок сохраняет поведение по умолчанию. Confidence 75, временная проверка скачка скорости, нулевой прочерк, веса, ONNX, владельцы ввода, сроки команд, DriveSafetyGate и C# не менялись.
