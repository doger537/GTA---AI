# Первая обученная модель: результат

Модель действительно обучена на записи пользователя и сохранена. Текущее качество недостаточно для самостоятельной езды. К GTA она не подключена.

Выбранный результат: `training/trained/2026-11-01T17-13-04-435Z/`. В папке находятся model.json, weights.bin, config.json, progress.json, run-status.json, checkpoint-evaluation.json и прогнозы на отложенных примерах.

## Что обучалось

- Небольшая CNN с 26 554 параметрами. Четыре RGB-кадра подаются в хронологическом порядке как 12 каналов, размер каждого 80×45.
- Шесть независимых выходов: W/A/S/D/Space/Shift, чтобы поддерживать одновременные кнопки.
- 659 примеров обучения, 213 примеров с конца той же поездки для диагностики. Восемь примеров убраны вокруг временной границы; зазор одна секунда, общих исходных изображений между частями нет.
- Три завершённые эпохи, примерно 474 секунды вычисления. Первоначальный запуск запрашивал восемь эпох; для первого диагностического результата он остановлен после сохранения третьей. Начатый фрагмент четвёртой не входит в выбранные веса. Новый запуск по умолчанию выполняет три эпохи и завершается штатно.
- Взвешенная бинарная ошибка с ограничением веса редких положительных меток; фиксированные начальные веса и перемешивание обучающей части с seed 42. Порог отчётных решений — 0,5, он не подбирался на проверочной части.

## Измеренное качество

| Показатель | Модель | Простой прогноз «всегда W» |
|---|---:|---:|
| Полностью совпал набор кнопок | 27,23% | 48,36% |
| Средний F1 по кнопкам с положительными примерами | 0,279 | 0,197 |

Разные показатели показывают разные свойства: модель иногда распознаёт правый поворот, однако делает много лишних поворотов и чаще ошибается во всём наборе кнопок.

- W: выбран на всех 213 проверочных примерах; в 74 случаях его не было в записи.
- A: пропущены все 23 положительных примера.
- S: пропущены все шесть положительных примеров.
- D: найдено 27 из 40 положительных примеров, но есть 98 ложных срабатываний. Точность среди предсказанных правых поворотов — 21,6%.
- Space и Shift: положительных примеров в проверочной части нет; качество этих действий не установлено.

Повторная загрузка модели и прогнозы проверены. Среднее время одиночного прогноза загруженной модели — 4,91 мс, максимум 10,87 мс на этой проверке CPU. Здесь нет захвата экрана, подготовки кадров и передачи игровых команд: это не полная задержка управления. При параллельной нагрузке результат меняется.

## Ограничения

Проверка использует конец той же двухминутной поездки. Это не независимый маршрут и не проверка поведения в игре. Исходные метки версии 1 предварительные: в них могли пропасть короткие нажатия. Данные несбалансированы, отдельные действия редки. Уменьшенное изображение теряет мелкие объекты; архитектура и настройки пока минимальные. По одному эксперименту нельзя отделить вклад этих причин.

У сети нет цели маршрута, измеренного тормозного пути или подтверждённого объезда препятствий. S может означать тормоз либо задний ход в зависимости от состояния GTA. Обучение не добавляет автоматически следование GPS или понимание аэропорта.

Следующий полезный этап: несколько коротких поездок рекордером версии 2 с разнообразными левыми/правыми поворотами и торможениями, плюс отдельная поездка для проверки. Затем сравнить варианты модели и параметры обучения по этим данным. Повторение одних прямых участков или увеличение числа эпох само по себе не подтверждает улучшение езды.

## Воспроизведение

Из папки GtaAutopilot:

```text
node train-bc.mjs datasets/2026-11-01T16-49-20-088Z --epochs=3
node evaluate-bc.mjs trained/2026-11-01T17-13-04-435Z
node predict-bc.mjs trained/2026-11-01T17-13-04-435Z datasets/2026-11-01T16-49-20-088Z --index=700
npm test
```

`Train-First-Model.cmd` запускает три эпохи на первом наборе. Новый запуск создаёт отдельную папку с весами и отчётом. `predict-bc.mjs` выдаёт только прогноз на сохранённом примере, без соединения с GTA.

35 тестов прошли, включая разделение по времени, отсутствие общих изображений, порядок каналов, метрики, один шаг обучения и сохранение/загрузку весов. Штатный полный цикл CLI дополнительно проверен на 80 равномерно выбранных примерах за одну эпоху: `training/trained/2026-11-01T17-22-36-521Z/`, config.smoke_test_only=true. Это техническая проба, её результаты не подменяют приведённую выше оценку основной модели.

Используется TensorFlow.js 4.22.0 на JavaScript CPU. Установка ускоренного Windows-пакета tfjs-node не удалась: официальный установщик получил 404 для готовой сборки; этот пакет не добавлен в зависимости. Исходники и сохранение модели через IOHandler основаны на [документации TensorFlow.js](https://www.tensorflow.org/js/guide/save_load) и [руководстве Node.js](https://www.tensorflow.org/js/guide/nodejs).
