# Перенос структуры — 7 ноября 2026

Реализована запрошенная структура `apps`, пяти `packages`, `training`, `experiments`, `tests`, `fixtures`, `configs`, `docs`, `models-manifest.json`, `.github/workflows`. Реализация исходников теперь в новых каталогах; прежние точки входа оставлены как переходники. Карта переноса содержит 261 файл, локальная резервная копия — `work/restructure/before`. Схема и команды: [архитектура](../ARCHITECTURE.md).

## Что изменилось

- C#-мост, сборка, CLI и launchers — `apps/gta-control`. `Build.ps1` принимает `-OutputPath`, чтобы проверять сборку в отдельном каталоге.
- Perception, navigation, control, actuation и protocols оформлены как приватные npm workspaces; зависимости/lock-файл и команды тестов в корне. Версии сторонних зависимостей сохранены.
- Обучение и Python-тесты используют импорты из корня. Сценарии, конфигурации и диагностика получили новые пути; benchmark-road разрешает пути изображений относительно JSON-конфигурации, manifest абляции хеширует канонические исходники.
- README, текущий статус, пути плана, AGENTS и CI обновлены. Публичные отчёты сохранены в `docs/reports`, прежние Markdown-ссылки ведут к ним.
- `models-manifest.json` содержит размеры/SHA-256 фактически установленных активов; `npm run models:verify` проверяет их без загрузки моделей. Неизвестное происхождение конкретных экспортов/лицензий не объявлено установленным.
- Каталоги данных связаны с прежними `D:/GTA-AI-data/*` через новые junction. Старые junction сохранены. Данные, веса, записи и результаты не перемещались и не удалялись.
