# Обновление зависимостей — 8 ноября 2026

Закрыты три high-позиции прежнего npm-аудита. В проверенном дереве `npm audit --omit=dev` возвращает ноль уязвимостей. Обновление проверено офлайн на сохранённых изображениях; игра, обычный мост, захват и исполнители ввода не запускались.

| Компонент | До | После | Назначение |
|---|---|---|---|
| sharp |0.34.5 |0.35.5 | Исправления библиотек обработки изображений |
| adm-zip внутри установщика ORT |0.5.18 |0.6.1, точный scoped override | Исправления чтения/распаковки ZIP |
| onnxruntime-node/common |1.23.2 |1.23.2 | Версия вычислительного runtime сохранена |

ONNX Runtime попадал в аудит через уязвимую транзитивную зависимость adm-zip. Scoped override обновляет эту библиотеку без смены ORT, DirectML и модели. Это не подавление advisory или изменение порога аудита. В `package-lock.json` закреплены версии и integrity; workflow по-прежнему запускает `npm audit --omit=dev --audit-level=high`.

Источники исправлений: [sharp0.35.5](https://sharp.pixelplumbing.com/changelog/v0.35.5/), [adm-zip0.6.1](https://github.com/cthackers/adm-zip/releases/tag/v0.6.1). Совместимость проверялась на текущем Node20.18.1 Windows.

Это повторная обработка исторического/development-материала. Одни сцены представлены многими соседними кадрами. Проверки не доказывают качество езды, полноту диапазона1–12км/ч или отсутствие ошибок на любых входах. Измерение ускорения не проводилось. Настоящая установка CUDA/NuGet с сетевой загрузкой не проверялась; Windows DirectML уже включён в пакет ORT.

Два runtime запускались последовательно в отдельных Node-процессах. Попытка загрузить обе версии sharp в один Windows-процесс выявила конфликт нативных DLL; она не использована для вывода о совместимости. Перед полноценными тестами кандидату добавлены ссылки на существующие записи; первый неполный запуск с отсутствующими записями не засчитан. Различия CRLF/LF при экспорте исходников исключены из сравнения кода, используемые конфигурации скопированы без изменения байтов.

## Воспроизведение

`experiments/tools/compare-runtime-dependencies.mjs` принимает два дерева со своими `node_modules`, моделями и конфигурациями. Manifest содержит массив `road` из `{path, sha256, baseline?}` и `hud` из `{path, sha256, geometry}`. Пути источников абсолютные; geometry — геометрия исходного native HUD. Положительный результат требует полного прохождения manifest, SHA-256 и всех сравнений; несовпадение завершает процесс с ошибкой. Каталог результата должен быть новым.

```powershell
node experiments/tools/compare-runtime-dependencies.mjs --baseline=C:/path/old-tree --candidate=C:/path/new-tree --manifest=C:/path/replay-manifest.json --out=C:/path/new-report
npm ci
npm run test:core
npm test
npm run test:python
npm audit --omit=dev --audit-level=high
```

Большие записи и manifest с локальными путями не публикуются. Локальные протоколы/результаты/предыдущие package-файлы находятся в `work/dependency-remediation-20261108/`, исходные записи сохранены. Предыдущая установка на `D:/GTA-AI-data/node_modules` и отдельная резервная копия сохранены для отката. Стандартный npm install заменил корневую ссылку обычным локальным каталогом; прежнее содержимое на D не удалялось. Текущий результат облачных проверок доступен в [Actions](https://github.com/doger537/GTA---AI/actions).

Это завершает обновление npm-зависимостей на указанную дату. Подтверждённая калибровка и runtime-источники identity/heading/metric по-прежнему отсутствуют; автономный gate остаётся закрыт по тем же условиям.
