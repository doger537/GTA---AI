## Реализовано и проверено офлайн

| Находка | Изменение | Проверка |
|---|---|---|
| Heartbeat продлевает решение независимо от кадра | Новый DecisionLease требует sequence/generation/capture_start/age; срок<=min(lease250, остаток450). Повтор того же sequence не продлевает срок; старые кадры/смена session отклоняются | Регрессии с поддельными часами, кадром возрастом400мс, повтором heartbeat и сменой поколения |

Сервер ограничивает duration и holdExpires этим deadline при обработке запроса; просроченный/слишком далёкий deadline отклоняется | JS-таймеры и Windows self-test проверки deadline до обращения к игровому окну |
| /hold обходит actionGate, пока /step ждёт кадр | /hold использует тот же actionGate; /stop остаётся вне него | Windows HTTP-тест удерживает реальный actionGate в другом потоке, проверяет409 с причиной Another action is running и доступность /stop |
| Старая --drive обходит строгий допуск | trial.mjs теперь только shadow; --drive отклоняется до подключения/захвата/создания устройства | Запуск CLI с--drive в тесте завершается ожидаемой ошибкой, без обращения к мосту |
| Trial использует уменьшенный HUD из JPEG | Shadow-trial переведён на единый /observation, native PNG HUD, исходные capture timestamps и sequence/generation/geometry checks | Синтаксис/базовые тесты; новый живой shadow-прогон не выполнялся |
| NaN времени отравляет историю Controller | Timestamp проверяется до изменения lastTime; NaN сбрасывает историю, нерастущее время отклоняется, отрицательные age/time запрещены | Корректный кадр→NaN→корректный: последующие команды конечны |
| Нет CI | ci.yml: core JS на Ubuntu/Windows, Windows C# build/self-test; security.yml: npm audit; Dependabot для npm/Actions | Локальные эквиваленты проверены; GitHub Actions ещё не запускался, файлы не опубликованы |

У LiveActuator убран аварийный1000мс space по просроченному наблюдению. Отказ прекращает продления и вызывает /stop; физическая остановка этим не подтверждается. Action-fallback для мостов без /hold запрещён. После fault тот же экземпляр исполнителя не перезапускается. Обычный клавиатурный lease уменьшен до250мс; это намеренное исправление правил управления, не performance-only изменение.

AnalogActuator также использует DecisionLease и требует метаданные исходного кадра. Это только клиентская часть: **полный deadline-контракт до Python/backend ещё не реализован**, прямые GamepadWorker/manual-calibration пути отдельно требуют проверки. Сокращение клиентского duration само по себе не доказывает соблюдение срока после очередей IPC. Существующая автономная нейтрализация backend не удалялась.

Серверный holdExpires не превышает capture deadline, но watchdog исполняется с периодом20мс и зависит от планировщика Windows. Это не обещание жёсткого realtime/момента физического отпускания. Старые ручные /hold без observation_expires_ms совместимы; новый LiveActuator этот deadline передаёт обязательно. После сборки/self-test и проверки отсутствия запущенного моста EXE заменён проверенной сборкой, SHA-256 совпал; прежний EXE сохранён. Мост и игра после замены не запускались. Параллельное кодирование доступно только отдельным флагом, по умолчанию выключено.

## Незакрытые пункты — обязательная очередь

1. **P0: единый владелец клавиатуры/геймпада.** Нужны owner/mode/generation/lease в мосте, резервирование для всех реальных gamepad entrypoints и проверка отзыва самим backend, включая падение Node. Добавить только Node-проверку busy недостаточно. Пока не реализовано.
2. **P1: общий DISARMED и явный re-arm после F8/stop/focus.** Новый экземпляр JS не заменяет серверный общий запрет. /action по-прежнему не требует новой общей сессии. Пока не реализовано.
3. **P0: единый полноценный DriveSafetyGate.** Старый обход --drive закрыт запретом, а не выдуманным разрешением от ещё не проверенных калибровок. Реальный маршрут управления не интегрирован; guidanceGate остаётся drive_allowed=false.
4. **Срок решения для всех путей, включая raw gamepad/calibration.** Нужен согласованный deadline на стороне Python, не только клиентский таймер. До этого нельзя считать весь пункт свежести закрытым.
5. **Зависимости и воспроизводимость.** Исправления ниже требуют отдельной проверки пикселей/моделей; manifest весов/лицензий и Python lock ещё не завершены.
6. **Функциональные зависимости.** Низкие скорости/камера/метрические габариты/торможение, остановка по новым наблюдениям, препятствия и GPS требуют данных и отдельных живых испытаний. Нет новых данных — нет заявления о готовности. Три inspected minimap crop и синтетический трассировщик не закрывают GPS.

Не планировать новые живые управляющие пробы как будто эти P0 уже исправлены. Пассивная диагностика и mock-тесты остаются допустимыми. Игру/реальный ввод в этой партии не запускали.

CI не использует self-hosted runner, connection.json, игровые записи или GTA. Удалённого запуска до push не было.
