# Конфигурации

Активные `gear-templates.json` и `segformer-config.json` сохранены из прежнего каталога моделей побайтно. `hud-digit-prototypes.json` относится к отключённому по умолчанию экспериментальному распознавателю. Хеши — в корневом `models-manifest.json`.

Остальные JSON и `sounds/` перенесены из прежнего приложения. Токен подключения хранится отдельно в игнорируемом `apps/gta-control/connection.json`. Пороги и калибровку перенос каталогов не меняет.
