# Раздельная проверка обработки и обучения

Все три запланированные части выполнены: раздельные сравнения, изменение яркости при обучении, сохранение и выбор промежуточных весов. Новая модель пока не обеспечивает качественное вождение.

## Метод

832 примера одной поездки используются для обучения; 880 примеров другой поездки — для проверки разработки. Последняя запись 2026-11-02T07-43-54-725Z не использовалась ни для обучения, ни для выбора профиля или эпохи. После выбора на ней выполнена одна оценка выбранного варианта.

Использован локальный PyTorch CPU с двумя вычислительными потоками. Python уже имелся в окружении; torch и onnx установлены в отдельный training-env проекта. Модель, начальные веса и правила обучения одинаковы внутри новой серии. Каждая модель обучается с нуля восемь эпох; все эпохи сохранены. Архитектура соответствует прежней небольшой CNN с согласованными выходами, однако порядок внутреннего представления и генератор начальных весов отличаются от TensorFlow.js. Поэтому сравнения факторов ниже проводятся между новыми PyTorch-запусками, не с прежними числами TensorFlow.js.

Критерий выбора зафиксирован до запуска: средний F1 для A/S/D на поездке разработки; при равенстве — полное совпадение кнопок. W не может один выиграть по этому критерию. Критерий не равен качеству езды и не оптимизирует общее совпадение кнопок.

## Сравнения на 880 примерах разработки

| Профиль | Что меняется | Выбранная эпоха | F1 A/S/D | Совпал весь набор кнопок |
|---|---|---:|---:|---:|
| rgb-v1 | Базовый RGB 80×45 | 8 | 0,124 | 31,93% |
| rgb-hi-v1 | Только размер: RGB 128×72 | 7 | 0,125 | 37,73% |
| gray-stack-v1 | Серый 128×72, четыре кадра | 6 | 0,132 | 42,50% |
| gray-mask-v1 | Серый + только маска кузова/HUD | 7 | 0,162 | 38,30% |
| gray-contrast-v1 | Серый + только CLAHE | 3 | 0,105 | 32,73% |
| gray-delta-v1 | Серый + только разности кадров | 8 | 0,128 | 35,68% |
| gray-mask-v1 + exposure | Маска + изменения яркости при обучении | 8 | 0,157 | 32,27% |

Маска дала лучший выбранный показатель в этой серии. Усиление контраста ухудшило его относительно простого серого входа. Разности кадров не превзошли четыре обычных серых кадра. Проверенная настройка изменения яркости также не превзошла вариант без неё. Это один seed и две короткие поездки; результат не устанавливает универсальную полезность или вред каждой операции. Изменение размера/числа каналов меняет и число параметров, тогда как маска/контраст/разности сравниваются на одинаковой форме входа.

Изменение яркости применяется только при обучении, одинаково ко всей истории одного примера; метки и геометрия не меняются. Нейтральные области маски восстанавливаются. Для разностных признаков смещение действует на яркость, а усиление — на разности; это приближённая операция над признаками, не физический рендер освещения.

## Инструменты и проверки

Семь восьмиэпоховых запусков заняли суммарно около 21 секунды вычисления, без подготовки данных, установки зависимостей и экспорта. Это замер данной небольшой сети на этом компьютере, не общая гарантия времени обучения. Подготовленные промежуточные тензоры находятся в work/autopilot/ablation-cache.

Сохранены ONNX-модели для загрузки из Node.js. Все семь экспортов проверены против PyTorch на одном одинаково обработанном примере: максимальная разница меньше 0,000001. Для выбранной модели измерено около 0,17 мс на ONNX CPU без захвата и подготовки изображения; это не полная задержка управления.

49 тестов Node.js и пять тестов Python прошли. Проверены одиночные различия профилей, маска и форма данных, согласованность временного изменения яркости, отсутствие выдуманного движения, выбор по редким действиям и экспорт. Файлы протокола, истории эпох, веса, таблицы и проверки экспорта лежат рядом с моделями.

Команды из GtaAutopilot:

```text
node prepare-ablation.mjs datasets/2026-11-01T17-32-01-342Z datasets/2026-11-01T16-49-20-088Z ../../work/autopilot/ablation-cache
training-env\Scripts\python.exe ablation_train.py ../../work/autopilot/ablation-cache trained/ablation-repeat --epochs=8
node onnx-controls.mjs trained/ablation-2026-11-02/gray-mask-v1 --verify
node onnx-controls.mjs trained/ablation-2026-11-02/gray-mask-v1 datasets/2026-11-02T07-43-54-725Z --evaluate
```

Установку локальных зависимостей можно повторить по requirements-training.txt. Использованы [официальная CPU-сборка PyTorch](https://pytorch.org/get-started/previous-versions/) и существующее окружение Python. Следующий предмет работы — признаки дороги и наблюдаемого движения, зависимость от намерения поворота и контролируемые данные для торможения. Дополнительная случайная поездка сама по себе эти проблемы не решает.
