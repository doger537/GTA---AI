# GTA ONNX: экспорт, соответствие и DirectML

3 ноября 2026. Офлайн-этап завершён: GTA EMA YOLOv8l-seg экспортирована в ONNX, численное соответствие проверено на прежних 40 кадрах, DirectML реально измерен на GTX 1660 SUPER (драйвер 617.14). Игра, мост и управление не запускались. Рабочий контур не заменён.

## Результат

| Режим | Полный анализ p50 / p95 | Инференс p50 / p95 |
|---|---:|---:|
| ONNX CPU | 1315 / 1440 мс | 1277 / 1403 мс |
| ONNX DirectML | **104 / 115 мс** | **67 / 70 мс** |

По два прогрева, затем три последовательных прохода по 40 кадрам (120 замеров каждого режима). Полный анализ включает JPEG decode, прежний letterbox, RGB/255, инференс, NMS, маски, восстановление исходного размера и сетку 128×128/боксы. Дисковый I/O, загрузка/экспорт, OCR, общая геометрия коридора, захват и управление исключены. Профилирование ORT включено в обоих режимах. Тесты проекта завершились до измеренных проходов.

Это повторные обработки одной development-поездки, а не 120 независимых сцен. Нагрузку всей системы не контролировали; измерений с активной GTA нет. Исторические 113/155 мс текущей системы получены в другой серии и в Node.js ORT 1.23.2, поэтому разницу с ними нельзя считать доказанным ускорением замкнутого контура. Лимиты наблюдения 450 мс и команды 250 мс сохранены.

## Соответствие

- SHA-256 всех 40 исходных JPEG сверены с прежним манифестом. PyTorch повторно точно воспроизвёл все сохранённые сетки road/obstacle/ego и боксы прошлого эксперимента.
- Граф float32, opset 17, фиксированный вход 1×3×640×640, выходы detections/prototypes; onnx.checker full_check прошёл. Предупреждение tracer о Python boolean в голове относится к фиксированной форме; другие размеры не поддерживаются этим экспортом.
- Критерии записаны в protocol.json до измерений: raw allclose atol=1e-3/rtol=1e-4; расхождение масок не более 0,1%; одинаковое число/классы боксов и отклонение координат/score не более 1e-4. Прежние confidence 0,6, IoU NMS 0,7 и обработка масок сохранены.
- CPU и DirectML прошли критерии **40/40**. Все три итоговые сетки 128×128 совпали побитово на **40/40** в обоих режимах. Боксы прошли допуск на всех кадрах.
- Сырые тензоры не побитово равны: максимальная абсолютная ошибка detections CPU 0,0026093, DML 0,0026856; prototypes 0,0000190 и 0,0000241. Комбинированный абсолютный/относительный допуск пройден. Максимальная доля различий полноразмерной маски 0,000004679 (0,000468%); obstacle совпала точно. Ошибки находятся до дискретизации в общую сетку.
- ORT-профиль содержит 122 события DmlExecutionProvider (два прогрева и 120 запусков), событий CPU-провайдера в DML-серии нет. CPU-серия: 63318 CPU-событий. Числа событий не сравнимы как число операций: DirectML объединяет граф.

Использованы torch 2.7.1+cpu, onnx 1.17.0, отдельный onnxruntime-directml 1.23.0 в ort-packages (--no-deps). Python-пакет 1.23.2 отсутствует в индексе; существующий Node runtime не менялся. Последовательное выполнение и отключённые memory patterns соответствуют [требованиям DirectML](https://onnxruntime.ai/docs/execution-providers/DirectML-ExecutionProvider.html).
